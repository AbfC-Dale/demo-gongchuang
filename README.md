# 智能分拣演示：GLB 优化试验版

此目录是独立试验副本。原 `D:\工创\output\智能分拣网页上传包` 未修改。

## 本地预览

GLB 由网页请求加载，因此请用本地 HTTP 服务预览，不能直接双击 `index.html`：

```powershell
cd D:\工创\output\GLB优化版
python -m http.server 8765
```

在浏览器打开 `http://localhost:8765/`。上传 GitHub Pages 时，将本目录的 `index.html`、`style.css`、`ui-glass.css`、`open-layout.css`、`app.js`、`scene-metadata.js`、`scene.glb` 放在同一发布目录。

手机打开公开链接后可直接浏览。点击操作区的「手机横屏展示」，将手机横过来，即可让上方比赛画面占满屏幕；右上角「退出横屏」返回。支持屏幕方向锁定的浏览器会尝试自动切换，其他浏览器会显示旋转提示。GitHub Pages 发布源应选存放 `index.html` 的分支根目录或 `docs` 目录。

## 试验结果

- 原上传包的场景数据 JS 合计约 26 MB；本版 `scene.glb` 约 3.7 MB，另有约 2.3 MB 的应用脚本。
- 保留 47 个独立模型网格及全部 408,089 个三角形，没有减面。Rz 轴位于上部壳体与丝杆上端连接面；两块底盘、四根导杆及丝杆组成随 Rz 转动的刚性支架，夹爪连接件沿导杆做 Z 向运动，丝杆还独立自转。
- 使用 Meshopt 压缩，位置和法线在解码后使用浮点顶点。未采用使本机 WebGL 渲染明显变慢的量化顶点方案。
- 浏览器整轮验证：12 件全部完整入盒，各盒 2 件；无页面异常。`加载完成.png` 为初始画面截图。
- 界面参考 [liquid-glass-js](https://github.com/dashersw/liquid-glass-js) 的玻璃层次、边缘高光和圆角风格。为避免与三维模型争夺 WebGL 资源，采用 CSS 绘制这些效果，未加入该库的实时折射画布。
- 配色以清华大学视觉形象识别资料中的清华紫 RGB (102, 8, 116)、`#660874` 为基准，搭配深紫、白色和少量暖金色。只调整界面与目标标记，六种货物的分类颜色保持不变。
- 开放式版面把模型、总数、料盒数量和说明文字直接排在浅色背景上；操作区只以背景色和留白区分，保留按钮与下拉框的操作提示。
- 模型右上角可分别控制镜头跟随与最外围铝型材机架的显示。镜头跟随默认开启：夹爪夹起物块后，视角随夹爪与目标盒平滑转动和缩放，投放时暂时隐藏外围机架；关闭跟随后视角停在当前位置，机架由显示按钮决定。演示进行中也可以切换。
- 模型文件固定为 3,900,032 字节（3.72 MiB）。加载画面按浏览器实际读取的字节数显示进度；读取结束后分别标示解码、场景组装和路径规划，不再把这些阶段当作文件下载百分比。字节数不符时会提示模型版本不一致。`加载进度.png` 为限速网络下的进度截图；如果以后替换 `scene.glb`，须同步更新应用源码中的 `MODEL_GLB_BYTES` 并重新构建 `app.js`。
- `source` 目录保留本次试验的加载代码与构建脚本；上线只需上述六个网页文件。

这是网页演示优化，不修改 SolidWorks 源装配体，也不代表实机的运动精度或接触力已验证。
